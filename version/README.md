# HTML 原型版本紀錄

此專案使用 `version/` 保存單檔 HTML 原型。根目錄的 [`index.html`](../index.html) 是目前工作的 v1.6 版本（文件更新：2026-11-12）。

| 版本資料夾 | 說明 |
| --- | --- |
| `Gemini-4-Argon_v1.0/` | 最初的單檔原型。 |
| `GPT-6_v1.1/` | 聚會圖示、咖啡色主題，以及發起揪團表單初始留白等介面調整。 |
| `Gemini_v1.2/` | 介於 v1.1 與 v1.3 之間的版本；詳細變更請以該資料夾內的 HTML 為準。 |
| `GPT-6_v1.3/` | 基於當時的根目錄 HTML，補齊英文與日文在發起揪團、揪團房間、歷史紀錄及動態內容中的翻譯。 |
| `Gemini_v1.4/` | 取消跳窗改為在房間頁直接顯示分享卡片；修復真實 GitHub Pages 連結生成與 Base64 編解碼；實作免設定跨裝置即時同步引擎（CloudSync）與分頁獨立身分機制。 |
| `Gemini_v1.5/` | 整合 Firebase Auth 帳號選擇與 Firestore 雲端同步；新增會員個人資料選單（常用暱稱自動代入、主要生活圈設定、登出）；修復拍板定案受邀者資訊顯示並改為深色置頂卡片；優化右上角圓形語言選單與會員 Icon 響應式排版；加入頁尾版權宣告。 |
| `Codex_v1.6/` | 2026-11-12：更新首頁三語介紹文案；分享按鈕改為「分享連結」與三點連線圖示，更新英日文；移除底部交易驗證說明；分頁標題改為「揪一下 \| 線上即時聚會協調」並支援三語切換；邀請連結精簡為原生短網址（`#room=SQ-XXXX`）並保留舊版長連結相容。 |

根目錄的 `index.html` 目前與 `Codex_v1.6/index.html` 內容相同。2026-11-11 的追加更新（`0da6fa2`）包含網站 Logo 與書籤圖示，並調整 Next.js 版頁首與 Open Graph 圖片。這裡的版本號標記原型迭代，不代表 `app/` 全端應用程式的版本（其套件版本為 `0.1.0`）。

備註：v1.5 檔案曾於本輪修改同步更新，保留其現有內容；v1.6 是本次正式建立的完整快照。產品規格文件仍標示規格 v1.5，與 HTML 迭代編號分開。
