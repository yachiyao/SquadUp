## 3. 網站內容與功能分析

### 3.1 核心使用流程

1. **建立活動：** 主辦人輸入活動名稱並設定候選日期、時間範圍等條件。
2. **分享連結：** 將活動連結傳給參加者，參加者輸入名稱後填寫可參與時間。
3. **檢視交集：** 利用群組時間表與熱度圖比較可行時段，供主辦人決策。

### 3.2 主要功能

| 功能 | 網站內容整理 |
|---|---|
| 建立活動 | 設定活動名稱、日期及時間範圍 |
| 日期選擇 | 支援選取 1～14 天的候選日期範圍 |
| 時間間隔 | 15、30、60 分鐘 |
| 免註冊參與 | 透過連結輸入名稱即可填答 |
| 時間投票 | 參加者選擇自己可參與的時段 |
| 共同時間視覺化 | 透過群組時間表、熱度圖呈現各時段參與人數 |
| 分享 | 支援活動連結與 QR Code |
| 跨時區 | 可依參加者時區檢視時間 |
| 行動裝置 | 支援手機與平板的觸控操作 |
| 自動儲存 | 填答資料可自動儲存 |
| 修改填答 | 透過參加者身分及選填密碼重新編輯 |
| 無法參加 | 可表達候選時間全部無法參與 |

### 3.3 限制與觀察

- **候選時間難以變更：** 先前網站內容顯示活動建立後無法修改日期範圍、每日時間範圍、時間間隔或活動時區，須重新建立活動。
- **欠缺全站會員歷史管理：** 主要以免註冊活動連結運作，未展示一般會員式的完整活動歷史管理流程。
- **活動資訊可見性：** 持有活動連結者可能看到參加者名稱與可用時間，須留意隱私設計。
- **參加者身分驗證：** 未設定密碼時，可能存在他人以相同名稱修改填答的風險。
- **服務範圍聚焦時間：** 官方首頁未展示專門的地點投票、主辦人最終決策公告或完整聚會後續管理流程。

> 註：上述「未展示」不代表產品所有頁面絕對沒有該功能；相關限制應在正式報告前透過實際測試複核。

## 6. 「揪一下」差異化策略

### 6.1 時間與地點的一站式協調

When2Meet Plus 擅長找出共同時間。「揪一下」可進一步讓參加者在同一活動中針對候選**時間及地點**提出意見與投票，減少額外使用通訊軟體或其他投票網站的需求。

### 6.2 從意見蒐集到主辦人定案

不僅統計票數，更要提供完整的決策狀態：活動建立、邀請、投票、主辦人決定、結果公告。主辦人決定後，參加者可在原連結直接查看最終時間與地點。

### 6.3 訪客便利性與會員長期管理並存

保留免註冊的低門檻，讓偶爾參與聚會的人輕鬆填答；對經常發起聚會的主辦人，則以會員功能提供歷史紀錄、活動管理與選擇性 E-mail 通知。

### 6.4 聚焦台灣日常揪團使用情境

產品介面與流程可優先針對朋友吃飯、看電影、社團活動等情境設計，降低初次使用者理解成本。

## 7. MVP（最小可行產品）建議

**優先開發：**

1. 免註冊建立活動與產生分享連結。
2. 訪客設定暱稱、參與時間投票。
3. 提供地點候選方案與投票。
4. 顯示投票統計，協助主辦人決定。
5. 主辦人公布最終結果；參加者透過原連結查看最新決議。

**第二階段：** 會員登入、歷史活動列表、E-mail 通知、QR Code 分享及跨時區支援。

**設計提醒：** 不應單純追求比競品更多功能；快速建立、免註冊參與與清楚的最後決策，仍應是核心使用體驗。

## 8. 分析總結

When2Meet Plus 是「揪一下」在**多人時間投票**上的直接競爭者。其競爭優勢是免費、免註冊、操作快速、時間交集視覺化，以及對手機和跨時區使用情境的支援。

兩者的差異化定位可設定為：

- **When2Meet Plus：** 幫助使用者「找出大家都有空的時間」。
- **揪一下（Squad Up）：** 幫助使用者「從邀約、時間及地點投票，到定案與結果通知，一次完成聚會協調」。

因此，「揪一下」的主要價值不是把時間投票變得更複雜，而是讓參加者**不需要再回到 LINE 群組反覆討論地點或確認結果**，降低一場聚會從提出邀請到真正成行的協調成本。

### 可放入專題企劃書的摘要

> When2Meet Plus 是一款多人時間協調平台，提供免註冊活動建立、時間投票、共同時段視覺化及跨時區支援等功能。其主要優勢為操作簡單、參與門檻低，適合會議、小組討論與朋友聚會等情境。該平台的公開產品介紹主要聚焦於時間協調，未展示完整的地點投票、會員歷史管理與聚會最終決策通知流程。因此，「揪一下」可透過整合時間及地點投票、主辦人決策與活動結果同步，建立更完整的一站式聚會協調體驗。
