| 項目 | 說明 |
|---|---|
| 產品／品牌名稱 | Doodle |
| 產品定位 | 線上排程、團體時間協調與預約管理平台 |

## 3. 網站內容與功能分析

### 3.1 主要產品功能

| 功能 | 內容 | 與「揪一下」的關聯 |
|---|---|---|
| Group Poll（多人時間投票） | 主辦人提出候選日期與時段，參加者表達可出席的時間，主辦人確認最終時間 | **高度重疊**，最直接的競爭點 |
| Booking Page（個人預約頁面） | 使用者公布可預約時段，供他人預約 | 偏向商務個人預約，非本專題優先方向 |
| Sign-up Sheet（活動報名表） | 讓參加者登記活動或不同場次 | 可作為未來擴充功能參考 |
| Calendar Integration（行事曆整合） | 與 Google、Outlook、Apple 等行事曆搭配安排時間 | 為 Doodle 優勢，揪一下目前未列入核心規劃 |

### 3.2 Group Poll 典型使用流程

1. **建立活動**：主辦人輸入活動資訊並列出候選日期／時段。
2. **分享連結**：將投票連結傳給參加者。
3. **參加者投票**：各自表達可參與的時間；常見選項包括「可以」「必要時可以」「不可以」。
4. **確認時間**：主辦人根據回覆選定時間，並通知參加者。

### 3.3 帳號、訪客與通知機制

- 主辦人建立投票需有帳號。
- 參加者可不註冊帳號參與，但訪客流程通常仍要求姓名與電子郵件。
- 參加者可以修改投票回覆，最終時間確認也可透過通知傳達。
- 免費方案提供基本團體投票；候選時段、管理及進階控制可能有限制。
- 自動提醒、投票截止時間及參加者資訊隱藏等功能，可能依方案而異。

> **注意**：產品介面、免費額度、必填欄位與各方案權益可能更新；正式發表專題時，應以 Doodle 當時的官方說明及價格頁再次核對。

### 4.3 揪一下可採取的差異化策略

1. **降低使用門檻**：參加者不需註冊、不需提供 Email，只輸入暱稱即可參與投票。
2. **時間與地點雙重投票**：同時解決「何時聚會」與「在哪聚會」，避免分散在不同聊天室或表單中協調。
3. **強化社交聚會情境**：以 LINE 群組、朋友聚餐、動漫活動揪團等日常使用場景設計手機優先的流程。
4. **即時協調與決策回饋**：投票更新、主辦人確認結果與同一連結查看決議，減少反覆詢問。

### 4.5 最終結論（可用於專題企劃書）

Doodle 是成熟的線上排程與多人時間協調平台，提供團體投票、預約管理與行事曆整合等功能，能有效降低多人安排活動時的溝通成本。

然而，Doodle 的整體定位較偏向商務會議與排程管理；建立投票需要帳號，未註冊參加者通常仍需提供電子郵件，且部分進階功能須訂閱付費方案。

相較之下，「揪一下」以朋友及社群聚會為主要目標市場，強調**免註冊參與、時間與地點雙重投票、即時結果更新、簡易分享機制**。核心競爭策略不是複製 Doodle 的完整商務排程能力，而是針對日常聚會提供更輕量、直覺且低門檻的協調體驗。

**MVP 開發建議**：優先完成「時間＋地點雙重投票」與「僅需暱稱即可參與」，以建立使用者最能直接感知的差異化價值。
