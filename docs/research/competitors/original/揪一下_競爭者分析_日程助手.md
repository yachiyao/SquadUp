## 3. 網站內容與功能分析

### 3.1 主要操作流程

1. **建立活動：** 主辦人輸入活動名稱、候選日期與時間，活動說明可以選填。
2. **分享連結：** 將活動連結發給朋友或群組，參加者不需註冊即可填寫出席意願。
3. **查看統計：** 主辦人查看各日期的回覆與人數，決定合適的活動時間。

### 3.2 功能盤點

| 功能 | 說明 |
|---|---|
| 建立活動 | 輸入活動名稱，說明可選填 |
| 日期選擇 | 月曆拖曳、多日期選取、依星期批次選取 |
| 時間選擇 | 同一天可設定多個候選時間 |
| 出席投票 | ○ 參加、△ 待定、× 不行，也可改為二選一 |
| 即時統計 | 彙整參與者回覆，顯示各日期人數 |
| 修改回覆 | 參加者提交後可再次編輯 |
| 回覆截止日期 | 可設定期限，但到期後仍允許回答 |
| 未回覆提醒 | 比對預定名單，產生提醒訊息供主辦人複製 |
| 結果匯出 | 支援 CSV，包含回覆、備註與統計資料 |
| 新回覆提示 | 管理頁顯示自上次造訪後新增的回覆 |
| 多裝置支援 | 電腦、平板、手機響應式介面 |

## 4. SWOT 競爭分析

| 類別 | 分析 |
|---|---|
| **S — 優勢 Strengths** | 免費無廣告、免註冊、操作快速、即時統計、支援多語言與 CSV 匯出，適合低門檻的臨時聚會。 |
| **W — 劣勢 Weaknesses** | 未提供電子郵件通知，功能偏重日期協調，未見完整會員歷史管理與地點投票的明確說明。 |
| **O — 機會 Opportunities** | 可延伸聚會地點投票、會員活動紀錄、通知整合與完整聚會決策流程。 |
| **T — 威脅 Threats** | 免費且成熟的基礎功能提高新產品競爭門檻；若新平台操作較繁瑣，使用者可能選擇既有工具。 |

> SWOT 為依據公開功能與市場定位進行的策略判斷，並非實際用戶訪談或量化調查結果。

## 6. 對「揪一下」的開發建議

1. **保留免註冊快速參加。** 讓訪客輸入暱稱便能投票，降低操作阻力。
2. **優先實作地點投票。** 除了「何時聚會」，還協助解決「在哪裡聚會」的問題，形成產品差異化。
3. **提供會員歷史紀錄。** 讓經常揪團的使用者查看進行中與過往活動。
4. **強化最終確認通知。** 主辦人做出決定後，參與者可從原連結查看更新，會員可選擇電子郵件通知。
5. **考慮日期批次選擇與 CSV 匯出。** 可列入後續版本，以提升建立活動與資料整理的便利性。

## 7. 最終結論

**日程助手屬於「揪一下」的高度直接競爭者。** 兩者都試圖減少多人聚會協調過程中的反覆溝通。

日程助手具備免費、快速、簡單與成熟日期投票等優勢。揪一下應避免只複製日期協調功能，而以**日期與地點共同決策、活動結果通知，以及會員歷史活動管理**作為差異化方向。

> **建議產品定位：** 不只是找出大家有空的時間，而是從時間、地點投票到最終確認，一站式完成聚會協調。
