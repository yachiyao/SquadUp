# 揪一下競爭者研究：When2Meet Plus

查核日期：2026-11-06（Asia/Taipei）。研究對象：https://when2meetplus.com/ 。

## 1. 結論與研究邊界

When2Meet Plus 是免費的多人可用時間彙整工具，與「揪一下」的時間協調功能直接重疊。官方明確表示它是獨立產品，並非 When2Meet 的關係產品或獲其背書；名稱中的 Plus 不應解讀為原版的付費方案。[官方關於](https://when2meetplus.com/about)

本研究先閱讀專案內《揪一下_競爭者分析_When2Meet_Plus.md》，再搜尋並讀取官方英文、繁中首頁、關於、資料與隱私及替代工具比較頁。原報告只作背景；「揪一下」功能仍以其中企劃描述為準，未驗證已實作。沒有建立真實活動、多人操作、付款或手機實機測試；功能確認代表官方文件明示，不代表已完成端對端驗收。

證據標示：**已確認**＝官方明述；**推論**＝研究判斷；**未知**＝目前公開證據不足。搜尋不到或頁面未展示，不等於不支援。搜尋結果包含 When2meet、WhenMeet.me、LockMeet、Toss-up 等其他產品，本報告未挪用其功能或價格。

## 2. 定位與使用流程

官方以小組討論、遠端會議及朋友聚會為使用情境，核心是把多人空檔集中比較，而非宣稱提供完整活動營運系統。將學生、社團及朋友群視為潛在客群合理，但沒有市占率、活躍人數或客群占比證據。[官方關於](https://when2meetplus.com/about)

文件描述的流程如下，並非本研究的操作紀錄：

1. 主辦人設定活動名稱、時區、候選日期、每日時段與格長。
2. 建立後分享活動連結或 QR Code。
3. 參與者以活動內名稱加入，可選填密碼，標記空檔或明確回報全部不能參加。
4. 檢查儲存狀態，必要時回到同一活動修改回覆。
5. 團體依時間統計商議安排。官方所說的「一起決定」不能直接當成具有主辦人按鈕定案、鎖票或公告通知的證據。[官方首頁與常見問題](https://when2meetplus.com/)

## 5. 與揪一下比較

揪一下欄位來自原參考報告，均屬規劃或建議；本研究未取得獨立需求規格與產品驗收證據。

| 能力 | When2Meet Plus | 揪一下背景規劃 | 研究判斷 |
|---|---|---|---|
| 免註冊時間協調 | 已確認 | 規劃提供 | 屬競爭基本條件 |
| 時間視覺化 | 已確認 | 原報告建議納入 | 應處理未填答與全數無法參加的差別 |
| 地點投票 | 未知 | 規劃提供 | 可展示自身完整流程，不能宣稱競品一定沒有 |
| 主辦人定案及原連結結果 | 專用流程未知 | 規劃提供 | 應讓投票中／已定案狀態明確可辨 |
| 會員活動歷史 | 會員列表未知；資料不自動到期 | 規劃提供 | 價值應落在找回與管理，而非只談保存 |
| E-mail 通知 | 會議邀請不寄送；其他通知未知 | 規劃會員可選收 | 要說明觸發時機及未註冊者取得結果方式 |
| 繁中與手機 | 官方明示 | 台灣情境導向；實作品質未驗證 | 繁中本身不是獨有差異 |
| 跨時區／QR Code | 已確認 | 跨時區尚未規劃；QR Code 為建議 | 評估需求後安排優先序 |

**策略推論：** 揪一下較有說服力的方向，是展示「時間與地點一起投票→主辦人定案→同一連結查看結果」的完整成行流程。免費、繁中、手機及免註冊已有競品基準，僅列功能數量不足以構成差異。尚無量化資料證明上述方向能提高成行率或縮短協調時間。

建議先驗證三個情境：所有人無共同時間時如何決策；已加入未填答者與明確不能參加者如何呈現；定案後再修改回覆或更換時間地點時，舊結果如何失效及通知。這些是揪一下的建議驗收情境，不是已測得的競品失敗案例。
